
# Rally Stage Generator

A procedural content generation system that creates
2D rally racing stages using Godot 4 and GDScript.

## Overview

This project explores how procedural generation can
be used to create varied rally stages. Users can
configure stage length, corner types, straights, and
other track features.

## Features

- Configurable stage parameters
- Randomized track layouts
- Multiple corner radii and hairpins
- Track self-intersection prevention

## How to Run

1. Install Godot 4.
2. Clone this repository.
3. Open the project in Godot.
4. Run the main scene.
5. Press R to generate another stage.
